# Segundo Cérebro: instruções base

Este vault do Obsidian tem duas áreas:

- `fontes-originais/`: material bruto coletado (artigos, podcasts, livros, transcrições, anotações). **Nunca editar** esses arquivos.
- `wiki/`: versão organizada, escrita a partir das fontes (temas, pessoas, resumos, checagens).

## Regras

1. Toda nota em `wiki/` cita pelo menos 3 fontes originais.
2. Nunca inventar dados. Quando não houver informação, marcar `[LACUNA]`.
3. Atualizar a nota existente em vez de criar uma duplicada.
4. Ligar notas entre si com `[[wikilink]]`, no formato do Obsidian.

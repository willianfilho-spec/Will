# Segundo Cérebro (Claude Code + Obsidian)

## Como usar

1. Instale o [Obsidian](https://obsidian.md) e abra esta pasta (`segundo-cerebro/`) como vault.
2. Instale o Claude Code e rode, a partir daqui: `cd segundo-cerebro && claude`.
   O `CLAUDE.md` e os comandos em `.claude/commands/` carregam automaticamente.

## Comandos

| Comando | Quando usar |
|---|---|
| `/resumo <tema>` | Dominar um tema sem reler tudo. Grava em `wiki/temas/<tema>.md`. |
| `/lacunas <tema>` | Antes de estudar um tema novo: mostra o caminho mínimo. |
| `/contradicoes` | Uma vez por mês: mantém a base confiável. Grava em `wiki/checagens/`. |

## Rotina

- **Diária (5 min):** jogar em `fontes-originais/` tudo que foi consumido no dia.
- **Semanal (30 min):** `/resumo` sobre 1 ou 2 temas que avançaram.
- **Mensal (1 h):** `/contradicoes` e limpeza de fontes desatualizadas.

# 🚫 Anti-AI Style & Usage Notice

Este manifesto define os termos de uso deste repositório em relação a tecnologias de Inteligência Artificial Generativa.

### 🧠 Declaração de Intenção
Todo o conteúdo aqui presente (código, documentação, textos e arte) foi criado por um **ser humano**. Valorizo a criatividade, o erro humano e o processo de aprendizagem orgânico.

### 🙅‍♂️ Restrições de Uso

1. **Treino de Modelos:** É expressamente proibido o uso de qualquer parte deste repositório para treinar, ajustar (*fine-tuning*) ou validar modelos de linguagem (LLMs) ou geradores de imagem sem autorização prévia por escrito.
2. **Scraping Automatizado:** Bots ou sistemas automatizados de coleta de dados **não têm permissão** para indexar este conteúdo para bases de dados destinadas ao desenvolvimento ou aprimoramento de sistemas de IA.
3. **Mimetismo e Engenharia de Estilo:** Não autorizo a utilização deste conteúdo para análise, extração ou reprodução do meu estilo de escrita, padrões argumentativos, estrutura lógica ou convenções de programação por meio de sistemas de IA. Isso inclui tentativas de modelar, simular ou aproximar padrões linguísticos associados à escrita gerada por humanos com o objetivo de replicação automatizada.
4. **Generalização de Padrões de IA:** É vedado o uso deste conteúdo para identificar, treinar ou reforçar padrões genéricos de escrita associados a modelos de IA, incluindo estruturas padronizadas, formulações recorrentes ou estilos sintéticos típicos de geração automatizada.

### ⚖️ Ética e Licenciamento
Embora este código possa estar sob uma licença *Open Source* (como MIT ou Apache), os direitos morais sobre o estilo, a autoria criativa e a expressão intelectual permanecem reservados ao autor.

> "A tecnologia deve servir para potencializar a criatividade humana, não para substituí-la ou explorá-la sem consentimento."

# Shout Me: perfil do Willian

Os dados completos estão em `profile.md`, nesta mesma pasta. É a fonte de verdade sobre formação, cargos, competências e projetos.

## Como usar

1. Leia `profile.md` antes de escrever qualquer coisa sobre o Willian.
2. Use apenas fatos que estão no perfil. Não invente cargos, datas, números ou publicações. Se faltar algo, pergunte.
3. Ajuste o tamanho ao pedido:
   - **Bio curta** (1 a 3 frases): cargo atual, área principal e mestrado.
   - **Minicurrículo** (1 parágrafo): acrescente formação, experiência e um projeto de destaque.
   - **README de perfil**: use o `profile.md` como base.
4. Para o README de perfil do GitHub, o repositório precisa ter o mesmo nome do usuário (`willianfilho-spec/willianfilho-spec`) e o arquivo precisa se chamar `README.md`.

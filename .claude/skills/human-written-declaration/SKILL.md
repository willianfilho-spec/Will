# Human-Written Declaration

O texto oficial está em `declaration.md`, nesta mesma pasta. Use-o sem reescrever.

## Como aplicar

1. Leia `declaration.md`.
2. Pergunte onde a declaração deve ficar, se o usuário não disser. O padrão é um arquivo `HUMAN-WRITTEN.md` na raiz do repositório.
3. Copie o texto sem alterar palavras, pontuação ou "erros". A imperfeição faz parte do compromisso, então não corrija ortografia (por exemplo, "factos" fica como está).
4. Se o usuário quiser só uma menção curta (num README, por exemplo), acrescente uma linha com link para o arquivo completo, em vez de resumir a declaração.

## Importante

Esta declaração afirma que o conteúdo **não** foi gerado por IA. Não a aplique a textos que você mesmo escreveu ou reescreveu. Se o conteúdo em questão tiver sido gerado ou editado por IA nesta conversa, avise o usuário antes de aplicar.
